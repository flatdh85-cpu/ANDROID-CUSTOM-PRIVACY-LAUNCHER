# Minimal OS V3 — Debloat contrôlé

État : planifiée, aucun APK V3 n'est encore publié.

V3 introduira un outil ADB legacy en dry-run et, lorsque la version Android le permet, un backend Shizuku facultatif. Chaque modification exigera un profil exact, une confirmation visible, un journal préalable et une stratégie de restauration. Le launcher constructeur et tous les composants critiques resteront protégés.

Critères avant publication : exécution unitaire des actions, arrêt sur erreur, rollback vérifié, refus des profils inconnus et tests téléphonie/SMS/LTE/Wi-Fi/Bluetooth/GPS après chaque lot.
