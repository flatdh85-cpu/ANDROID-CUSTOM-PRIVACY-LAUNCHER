# Versions de Minimal OS

Ce dossier conserve les APK téléchargeables et décrit l'évolution prévue de l'architecture. Une version annoncée comme planifiée ne contient pas encore d'APK et ne doit pas être présentée comme fonctionnelle.

| Version | État | Périmètre |
| --- | --- | --- |
| [V1](V1/README.md) | Disponible | Launcher HOME minimal et diagnostics, strictement audit-only |
| [V2](V2/README.md) | Planifiée | Inventaire, profils exacts et journal de récupération |
| [V3](V3/README.md) | Planifiée | Debloat contrôlé via ADB/Shizuku avec protections |
| [V4](V4/README.md) | Planifiée | Red Button, compagnon de récupération et retour HOME natif |

Les versions V2 à V4 seront ajoutées seulement après implémentation, tests automatiques et validation sur appareils compatibles. La caméra, le coffre et la réplication hors ligne viennent après le launcher et la récupération fiable.
