# Minimal OS V4 — Récupération et Red Button

État : planifiée, aucun APK V4 n'est encore publié.

V4 ajoutera un compagnon de récupération indépendant et le Red Button. La procédure vérifiera le launcher natif, rendra le rôle HOME via les mécanismes Android officiels, proposera séparément les désinstallations autorisées et supprimera Minimal OS en dernier. Le debloat constructeur restera appliqué.

Critères avant publication : interruption et reprise, launcher natif absent, Shizuku/ADB indisponible, désinstallation partielle, permissions refusées et confirmation qu'aucun média du futur coffre n'est supprimé.
