# Minimal OS V4 — améliorations après essai sur deux téléphones

État : planifiée, aucun APK V4 n'est encore publié.

V3 fournit déjà une procédure Panic guidée et un transfert chiffré sur Wi-Fi local ou hotspot. V4 reste prévue pour les fonctions non validées : découverte authentifiée, Wi-Fi Direct/BLE si les appareils le supportent, coffre privé indépendant et compagnon de récupération. Le debloat constructeur demeure une simulation tant que les profils et outils de restauration ne sont pas vérifiés.

Critères avant publication : essais physiques A↔B, interruptions, stockage plein, permissions refusées, désinstallation partielle et récupération après redémarrage sur les modèles cibles.
