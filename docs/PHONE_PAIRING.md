# Associer deux téléphones en V5

Installez **le même APK V5 sur A et B**. Une V5 ne peut pas synchroniser avec une V4 : le protocole a changé pour transmettre les erreurs du récepteur. Aucun Wi-Fi commun, hotspot ni Internet n'est nécessaire.

1. Lors de la configuration initiale seulement, accordez l'accès complet aux photos/vidéos et l'autorisation radio Android. Sur Android 14+, l'accès limité à des photos choisies ne suffit pas pour toute la galerie. Ces permissions ne sont plus demandées à chaque copie ; Android peut les retirer plus tard dans ses réglages.
2. Ouvrez **Copie entre téléphones** sur A et B. Recopiez manuellement le même code de 32 caractères sur les deux ; gardez-le privé. Sélectionnez l'autre téléphone sur chacun, puis activez **Démarrer la réception directe** sur les deux.
3. Pour **Bluetooth direct**, associez initialement A et B dans les réglages Bluetooth Android, puis touchez **Chercher les appareils** dans Minimal OS et choisissez le téléphone voulu. L'application ne demande plus un nouvel appairage RFCOMM lors des copies suivantes : elle vérifie le code, puis chiffre chaque copie. Android ou un fabricant peut encore imposer une confirmation exceptionnelle. La réception doit rester active ; selon Android, sa notification peut être masquée sans permission de notification. Bluetooth peut être lent pour de grandes vidéos.
4. Pour **Wi-Fi Direct**, activez le Wi-Fi et, si Android le demande, la localisation. Recherchez et sélectionnez le pair sur les deux appareils. Android peut demander d'accepter la création du groupe P2P, y compris lors d'une reconnexion : l'application ne peut pas supprimer une confirmation imposée par le système. Si vous voulez une copie sans dialogue à chaque tentative, utilisez Bluetooth après l'association initiale.
5. Choisissez l'intervalle 10/15/20/30 minutes et **Enregistrer et planifier** sur un seul téléphone ; l'autre reste en réception. Une session copie dans les deux sens. Testez **Copier maintenant A ↔ B** et ouvrez **Voir les copies reçues**. Avec Wi-Fi Direct, si le téléphone de départ devient chef du groupe, lancez la copie depuis l'autre.

Si la copie Bluetooth échoue, ouvrez **Copie entre téléphones sur les deux appareils**. L'émetteur indique désormais si le code diffère ou si la galerie du récepteur est inaccessible. Le récepteur affiche son **État du récepteur** et l'adresse réellement connectée si elle diffère de l'appareil enregistré. Vérifiez que les deux APK sont V5, que le code et les appareils sélectionnés correspondent, que les deux radios et la réception sont actives, puis relancez. Aucune galerie n'est effacée après un échec de copie.

Android et le fabricant peuvent retarder les jobs, couper les radios ou arrêter le service au premier plan ; la cadence n'est pas garantie. Avant Panic, vérifiez une copie manuelle complète. Les sessions radio et la procédure Panic exigent encore des essais physiques sur deux téléphones.
