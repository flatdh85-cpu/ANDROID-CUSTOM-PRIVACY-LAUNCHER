# Protocole de copie directe V5

La V5 propose Bluetooth classique RFCOMM et Wi-Fi Direct, sans réseau Wi-Fi ou hotspot commun. Bluetooth utilise un socket RFCOMM *sans demande de nouvel appairage à chaque connexion*. Le transport radio ne fournit alors pas son propre chiffrement ; le protocole Minimal OS authentifie le code partagé et chiffre la session de bout en bout avec AES-GCM. L'adresse Bluetooth enregistrée sert aux connexions sortantes ; un entrant est accepté seulement après authentification du code et son adresse réelle est affichée. Les permissions Android et l'association initiale restent obligatoires. Wi-Fi Direct négocie un groupe P2P et TCP 38742 reste limité à ce groupe. Android peut demander confirmation de groupe ; l'application ne peut pas l'éviter de manière garantie.

La version de protocole V5 n'est pas compatible avec V4 ; installez la même version sur les deux téléphones. Après le défi-réponse mutuel, chaque côté transmet un état chiffré de sa galerie avant les manifestes. Une permission galerie refusée ou un stockage local inaccessible est donc renvoyé au pair au lieu de se transformer en simple fermeture de socket. La coupure avant l'authentification affiche une aide pour vérifier le pair, le service récepteur et le code ; le récepteur conserve son dernier échec dans ses préférences privées pour diagnostic.

Chaque session compare les manifestes, copie les fichiers manquants dans les deux sens par blocs de 64 Kio, reprend les blocs confirmés et émet un reçu authentifié après vérification de la taille et du SHA-256. Les originaux restent locaux ; les suppressions ne sont jamais propagées. Les copies reçues sont dans l'espace privé de l'APK. Aucun transfert individuel ne demande de validation dans l'application après la configuration initiale.

`JobScheduler` demande une tentative après 10/15/20/30 minutes sans condition de réseau Internet. Le pair doit garder sa réception au premier plan. Android peut retarder ces jobs. Dans une foule dense, aucun canal Wi-Fi ou Bluetooth n'est garanti libre ; le débit et la reconnexion doivent être mesurés sur les téléphones cibles. La V5 ne fournit toujours pas de QR d'identité, de BLE ou de coffre indépendant de l'APK.
